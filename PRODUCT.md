# Product

## Register

product

## Users

Developers using macOS editors, messaging apps, browsers and terminals. They invoke voice intentionally while working in another app, then paste the generated result themselves.

## Product Purpose

Voxen combines voice intent, the foreground app, an available website hostname and optional highlighted text to produce destination-appropriate writing. AssemblyAI transcribes; The selected OpenRouter model generates the result, with Gemini 3.1 Flash-Lite as the default writer and selective native Google research helper. The command center provides modes, writing preferences, local response history and settings. Writing has Style, About you and Platforms tabs; personal context is explicitly entered and opt-in, never inferred through background monitoring.

## Brand Personality

Minimal, practical, developer-friendly. Existing identity is a mint audio/V mark and a charcoal status capsule. Preserve that identity.

## Anti-references

Oversized overlays, provider-progress essays, redundant menu status lines, duplicate mode labels, busy settings pages, decorative animation and automatic field insertion.

## Design Principles

- Keep recording feedback to one status line.
- Put configuration in one predictable sidebar destination.
- Show only generated responses in history, clearly attributed to their captured app or hostname.
- Preserve the user's control over copying, deletion and local storage.
- Retain native keyboard navigation and platform permission controls.

## Accessibility & Inclusion

Native focus states and labelled controls, system light/dark appearance, reduced motion, and status conveyed by text as well as color. The overlay never steals focus. Details for errors belong in the command center when the menu is simplified.
